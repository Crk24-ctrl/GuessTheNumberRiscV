# RISC-V Guess The Number (RARS)

Two RISC-V assembly programs:
- `project.asm` — Guess-the-number game with difficulties and input validation (RARS/venus syscalls).
- `riscv1.asm` — demo that prints a string and computes its length.

## Run (RARS)
1. Open in RARS or venus.
2. Assemble and run.

Syscalls used: print_string(4), print_int(1), read_int(5), random(30), exit(10).
